# EverPeak Retail Analysis - Movilidad-Urbana-y-Productividad-Econ-mica-en-Ciudades-Latinoamericanas
Análisis de la relación entre congestión vial y desempeño económico en ciudades latinoamericanas mediante datos abiertos de movilidad y productividad. Incluye limpieza, integración y exploración de información para identificar patrones y apoyar decisiones sobre infraestructura y planeación urbana.
